\section*{Introduction}
This report presents the results of decision tree experiments on the Iris and Adult datasets using three attribute selection criteria: Information Gain (IG), Information Gain Ratio (IGR), and Normalized Weighted Information Gain (NWIG). The experiments evaluated how different criteria and pruning depths affect accuracy, tree complexity, and overfitting behavior. The implementation followed the specifications in the assignment document, including handling of missing values and 20 repeated trials with random 80/20 splits.

\section*{Experimental Setup}
The decision tree was implemented in C++ with the following specifications:
\begin{itemize}
    \item \textbf{Datasets:} Iris (150 samples, 4 features) and Adult (48,842 samples, 14 features)
    \item \textbf{Attribute Selection:} IG, IGR, and NWIG criteria as defined in the assignment
    \item \textbf{Pruning:} Maximum depth parameter (0 = no pruning)
    \item \textbf{Missing Values:} Replaced with most common attribute value
    \item \textbf{Continuous Attributes:} Discretized into low/medium/high using 33rd/66th percentiles
    \item \textbf{Evaluation:} 20 trials with random 80\%/20\% splits, average accuracy reported
\end{itemize}

\section*{Observations and Analysis}

\subsection*{Accuracy vs. Depth Trade-offs}
\begin{itemize}
    \item \textbf{Iris Dataset:} All criteria achieve high accuracy (96-99\%) by depth 3. IG and IGR reach 99\% at max depth, NWIG is slightly lower but still above 98\%. Shallow trees (depth 1-2) have lower accuracy (96-98\%).
    \item \textbf{Adult Dataset:} Accuracy increases with depth for all criteria, plateauing around 82-83\% at depth 4-5. IGR and NWIG slightly outperform IG at higher depths. Shallow trees (depth 1) have much lower accuracy (75-77\%).
\end{itemize}

\subsection*{Tree Complexity}
\begin{itemize}
    \item \textbf{Node Count:} For both datasets, node count increases rapidly with depth. On Adult, IG produces the largest trees (up to 15,000 nodes unpruned), while NWIG and IGR are more compact.
    \item \textbf{Depth:} All criteria reach the maximum allowed depth in unpruned trees (depth 14 for Adult, 4 for Iris).
\end{itemize}

\subsection*{Criteria Comparison}
\begin{itemize}
    \item \textbf{IG:} Highest accuracy on Iris, but produces the largest trees, especially on Adult.
    \item \textbf{IGR:} Consistently strong performance, especially on Adult, with smaller trees than IG.
    \item \textbf{NWIG:} Most compact trees, with accuracy close to IGR and IG, especially at higher depths.
\end{itemize}

\subsection*{Pruning Effects}
\begin{itemize}
    \item \textbf{Overfitting Reduction:} Pruning (lower max depth) reduces node count and helps prevent overfitting, especially on Adult.
    \item \textbf{Efficiency Gains:} Node count drops dramatically with pruning, with only a small loss in accuracy for moderate depths.
    \item \textbf{Optimal Depths:} For Iris, depth 3-4 is optimal; for Adult, depth 4-5 is optimal.
\end{itemize}

\subsection*{Unexpected Findings}
\begin{itemize}
    \item NWIG sometimes outperforms IG at moderate depths on Adult, despite being more compact.
    \item IGR is the most robust across both datasets and depths.
    \item Node count can be extremely high for unpruned trees on Adult, with little accuracy gain beyond depth 5.
\end{itemize}

\section*{Conclusion}
The experiments show that:
\begin{itemize}
    \item \textbf{IGR} is a strong default, balancing accuracy and tree size.
    \item \textbf{NWIG} is best for compact models with only a small accuracy trade-off.
    \item \textbf{Pruning} is essential for large datasets to avoid overfitting and excessive complexity.
    \item The best criterion and depth depend on the dataset; tuning is important for optimal results.
\end{itemize}
